## 工程量计算常见术语

| 术语 | 含义 |
|------|------|
| 清单计价 | 按工程量清单计价规范报价 |
| 定额计价 | 按地区定额站发布的定额计价 |
| 综合单价 | 人工+材料+机械+管理费+利润 |
| 措施费 | 非实体工程费用（如脚手架、模板） |
| 规费 | 政府规定必须缴纳的费用 |
| 税金 | 增值税（一般计税9%/简易计税3%） |

## AI + 工程 常用提示词模板

### 进度管理
```
你是一位有10年经验的工程项目经理。
我正在管理一个[项目类型]项目，当前进度滞后[天数]天。
请帮我分析：
1. 滞后的主要原因
2. 赶工方案（增加资源/调整工艺/并行施工）
3. 具体赶工建议（可操作）
```

### 成本分析
```
你是一位工程造价专家。
我有一个[项目类型]项目，以下是最新成本数据：
[粘贴成本数据]
请帮我：
1. 分析成本偏差（偏差率）
2. 找出成本超支的主要原因
3. 提出成本控制建议
```

### 安全检查
```
你是一位资深工程安全专家。
请帮我识别以下场景中存在的安全隐患：
[描述场景或粘贴照片描述]
请给出：
1. 隐患清单（按严重程度排序）
2. 整改建议
3. 依据规范条款
```

### 施工方案
```
你是一位有15年经验的技术负责人。
我需要编制[分部分项工程]专项施工方案。
工程概况：
[填写工程概况]
请帮我梳理：
1. 施工方案框架（章节目录）
2. 关键技术要点
3. 需要重点论证的内容
```
