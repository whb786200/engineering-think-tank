# 封面风格预设 · 工程人智库

## 风格一：工程蓝 · 极简科技

**适用**：技术实战类文章  
**提示词模板**：

```
极简封面图，[主题关键词]，蓝色科技感，
工程现场与AI芯片融合，深蓝(#1A6DB5)主色调，
留白充足，适合微信公众号封面，1536x1024
```

**色彩规范**：
- 主色：`#1A6DB5`（工程蓝）
- 辅色：`#4A90D9`（亮蓝）
- 背景：`#F0F4F8`（浅灰蓝）

## 封面文字叠加规范

封面图生成后，用 HTML 叠加文字（由排版脚本自动处理）：

```html
<!-- 封面文字区域 -->
<div style="
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  background: linear-gradient(transparent, rgba(0,0,0,0.7));
  padding: 30px 40px;
  color: white;
">
  <h2 style="margin:0;font-size:28px;font-weight:bold;">[文章标题]</h2>
  <p style="margin:8px 0 0 0;font-size:14px;opacity:0.9;">工程人的智库</p>
</div>
```
